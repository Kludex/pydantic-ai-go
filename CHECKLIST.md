# PydanticAI Feature Parity Checklist

This is the living source of truth for parity work. Update it whenever a feature lands, a gap is discovered, or an API decision changes.

Audited upstream target: `pydantic/pydantic-ai@23a48cf2f9fe906029342852af9d10853f6d798d` from baseline `3a3e5612786c64e19312f20e3c998553edf1353b`. Follow-up audits cover capability composition, typed events, recursive tool-return content, provider profiles, context windows, `genai-prices` v0.1.6, background pricing refresh, and realtime barge-in. `.upstream-sync.json` remains unchanged for this audit.

Python-only type-overload and error-helper refactors require no Go runtime change because Go constructors are explicit and the direct HTTP embedding adapters already share their error paths.

Status:

- [x] Implemented and covered by public-API tests.
- [~] Partially implemented or behavior differs from upstream.
- [ ] Not implemented.
- [-] Intentionally excluded. The reason must be recorded.
